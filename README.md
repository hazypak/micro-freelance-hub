# 🚀 Microfreelance Hub

A full-stack platform empowering micro-freelancers to showcase services, manage client gigs, and track workflow telemetry. Built and shipped for Hack Club's Stardance!

## ✨ Features
- **Service Showcase:** Clean UI cards detailing service scope, turnaround times, and pricing tiers.
- **Gig Management Dashboard:** Dynamic views to manage incoming client requests and active micro-services.
- **Live Telemetry:** Workflow tracking for freelancers and clients to monitor ongoing milestones and progress states.

## 🤖 AI Usage Declaration
**This project utilized AI heavily to accelerate the workflow.**
I used Claude Code connected via Omni Router (which required logging into 44 free providers just to stack enough tokens for the build). 
- **What AI built:** Scaffolding initial UI components, generating utility functions, and debugging API routes and environment setup. AI was also my debugging partner through a saga of 27 separate `503 Service Unavailable` errors.
- **What I built manually:** The overall full-stack architecture, core business logic, integrations, and final Vercel deployment configurations were written and implemented entirely by me.

## 🛠️ Tech Stack & Deployment
- **Frontend & UI:** Full-stack framework with Tailwind CSS
- **Deployment:** Vercel
